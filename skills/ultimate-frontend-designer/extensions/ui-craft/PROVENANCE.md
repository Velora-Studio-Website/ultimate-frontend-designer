# Source and implementation boundary

This is UI Craft, an independent extension based on public Oil UI sources, not an official edition of Oil UI. This public distribution contains no private Oil Pro module. The vendored upstream subtree is separately attributed below.

Foundation: https://github.com/oil-oil/oil-ui ; observed Git tree identity `feb1f95e8cec48bb8ba35181cb66f94f23b1b6fc`, entrypoint version 0.23.8, copied from the verified local installation on 2026-10-21. Every vendored file was checked against its Git blob identity in that pinned public tree; source-manifest.json records SHA256 values. Vendored files are byte-preserved public method references, three scripts and their comparison assets; see [MIT license](vendor/oil-ui/LICENSE). Third-party font licensing remains beside the font. No upstream updater, recommendation script or discovery entrypoint is included.

The public feature categories were researched at https://ui.oiloil.org/intro/ and https://github.com/oil-oil/oil-ui . New interaction, renovation, review, component laboratory and evidence-ledger work is independently authored. Similar category coverage does not establish identical implementation, proprietary source reconstruction, or equal design outcomes.

The integration keeps the Ultimate Frontend Designer entrypoint as authority; original public reference files remain subordinate supporting material. Automatic updates of this extension from upstream are intentionally absent: a maintained update requires reviewed source changes and validation.
