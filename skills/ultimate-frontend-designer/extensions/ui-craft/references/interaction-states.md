# 交互状态与恢复

本参考为独立编写的公开扩展规则，不包含专有 Pro 内容，也不声称功能或质量对等。按当前任务选择适用规则；入口与阶段约束见 [GUIDE](../GUIDE.md)，演示入口见 [组件实验室](../assets/component-lab.html)。本文件不替代 UFD 的 image-first 流程及 Design/Build 门禁，不自行触发付费生成。

## 先定义转换，再画状态

对用户将要执行的关键动作，写清「当前状态 → 触发 → 目标状态 → 失败退路」。数据状态与请求状态分别表达：已有数据刷新中，不等于首次加载；保存失败，不等于表单内容失效。只实现任务真实需要的分支，不能为凑状态而编造业务。

| 条件 | 界面与转换规则 | 恢复出口 |
| --- | --- | --- |
| 首次读取尚未完成 | 显示明确加载语义；仅在最终结构可预测时使用骨架，避免伪造数据 | 失败后结束加载，给重试；有取消能力才提供取消 |
| 已有数据正在刷新 | 保留可用内容，标出更新状态；旧数据可能影响决策时显示更新时间 | 刷新失败保留旧内容并提示其时效，不清空整个页面 |
| 请求成功但没有数据 | 区分首次使用、筛选无结果、列表已处理完；各自提供创建、清筛选或返回任务 | 不把无权限、离线或接口失败包装为空态 |
| 读取或提交失败 | 说明失败动作及可执行下一步；字段错误就近显示，全局错误集中呈现 | 保留输入与上下文；可重试才显示重试，不暴露内部堆栈 |
| 离线或连接不确定 | 网络提示只是线索，仍以请求结果判定；说明哪些内容可读、哪些动作受限 | 只有存在持久队列和去重机制才承诺稍后同步，并允许检查或取消待提交项 |
| 缺少权限或会话过期 | 区分登录过期、功能权限、资源不存在；仅披露允许公开的信息 | 提供重新登录、返回或真实存在的申请入口；前端隐藏按钮不能替代服务端鉴权 |
| 版本冲突或资源被修改 | 停止覆盖，保留本地草稿，展示可比较的差异与服务端版本 | 提供重载、复制草稿或合并；强制覆盖须有权限和明确确认 |

## 提交、读回与异步竞态

- 当用户提交修改时，区分「未保存 → 提交中 → 服务端已确认 → 读回已确认」。响应成功但返回值不完整时，读取权威数据后再声称结果已持久化；若提交已确认、读回失败，显示“已提交，确认结果暂不可用”，保留动作标识，避免诱导重复提交。
- 当请求超时而结果未知时，先通过记录 ID、幂等键或状态查询确认结果；支付、创建订单等动作不能直接盲重试。前端禁用重复点击只解决界面重复操作，不能代替服务端去重。
- 当搜索、筛选、切换详情或校验可并发时，按请求序号、资源 ID 和当前参数接纳结果；取消旧请求之外仍检查结果归属。旧响应不得覆盖新查询、切换后的表单或已关闭的对话框。
- 当请求期间仍允许编辑时，记录提交快照；成功只确认该快照，不清除之后的新输入。自动保存按版本串行或显式解决冲突；“已保存”必须对应实际确认的版本。
- 当采用乐观更新时，先确认动作可撤回、冲突策略明确；失败回滚该次变更，保留后续有效操作。不可恢复的动作应等待权威确认，不能用成功动画掩盖未知结果。
- 当错误可恢复时，把重试放回原任务位置并保留字段、筛选、滚动和选择；离开存在未保存内容时，提供明确的保留或放弃路径。草稿若含敏感数据，按项目存储策略处理，不默认写入本地存储。

## 表单、对话框与键盘

- 当收集输入时，优先使用原生表单控件和可见标签，关联提示及错误；占位符不替代标签。保留原始输入，按业务约束校验，避免输入法组合期间误提交。提交失败时，长表单聚焦错误摘要并链接字段；短表单可聚焦首个无效字段，不在每次输入时抢焦点。
- 当状态变化需要播报时，用适当的状态区域简短通知；普通保存反馈不抢焦点，紧急错误才使用强提醒。禁用操作时，同时说明原因和解除条件，不能让用户只看到一个无法点击的按钮。
- 当弹出模态对话框时，提供可访问名称、可见关闭或取消入口，隔离背景并把焦点放到合理起点；危险确认优先聚焦安全选项。Tab 留在模态内，关闭后回到触发器；触发器已消失则回到邻近任务位置。
- 当 Escape 或点击遮罩可能丢失编辑内容时，先提供保留或放弃选择；不能用无出口模态保护草稿。非模态侧栏不应无故锁住页面或困住焦点。
- 当提供菜单、标签页、列表框等复合控件时，遵循相应语义与键盘模型；优先可靠原生实现。所有操作有可见焦点，不只依赖悬停；单键快捷键须避免在输入区触发，并提供关闭或改键方式。

## 小屏与减少动态效果

- 当软键盘打开或视口变窄时，当前字段、错误和提交入口仍可到达；固定底栏不得遮挡焦点。双栏表单按阅读顺序折叠，长对话框允许内部滚动，关闭入口保持可达。
- 当交互依赖拖动、悬停、精细点击或滑动时，补充可见按钮、选择后移动等触控与键盘路径；布局折叠后保留选择和未保存输入。
- 当系统请求减少动态效果时，移除非必要位移、视差和循环动画，以即时变化或轻量渐变表达状态；保留进度文字和焦点反馈。动画结束不能成为完成提交、显示错误或恢复操作的必要条件。
