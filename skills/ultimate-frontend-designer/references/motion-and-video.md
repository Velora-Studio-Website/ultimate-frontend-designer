# 关键帧、MiniMax H3 与动画实现

animate 分支可仅使用 UI motion 或 3D；二者不要求生成视频。只有 generated_video 已选择时才执行 `keyframes`、`video` 和下述 H3 生产契约。只有 generated_video.selected 显式为 false 且记录理由时，两阶段才记 not_applicable，不把已确认的 UI-only 视为缺素材。selected=pending 保持未决，允许独立准备，不按 false 跳过视频阶段或据此进入 prebuild_review；若可能实质改变必要素材，阻止完整 Design Gate 验收通过。selected=true 仍须完成下述 H3 生产要求。

## UI motion 与 3D

先说明动效帮助哪项任务、响应什么输入、能否中断及静态等价内容。根据现有栈选择 CSS、Motion、GSAP、React Bits 或 3D，不强制引擎、单点数量或滚动视频。保持相同行为一致；避免无目的的每区入场与卡片浮起，状态反馈可重复。预留稳定尺寸，检查键盘/触控替代、资源清理、加载失败和 reduced-motion；快速操作不被演出阻塞。3D 提供可理解的静态/文字替代，限制媒体负载并在目标设备实测。non_animate 保持无装饰动画的即时反馈。

## 关联关键帧（仅生成视频）

保留 4–10 张独立关联关键帧，按场景建立、主体展示、细节变化和收束组织。关键帧数量不等于视频数量，也不固定对应 2–5 段；可复用连续镜头的边界帧。先明确每个节点的表达目的，再依据工具实际输入能力映射到少量足够的镜头。设计系统板、Logo 板和页面稿不计入；多格故事板不能冒充多张独立图片。

先说明动画解决什么问题：展示结构变化、空间关系或叙事进展。为每个动态段记录触发方式、文字安全区、开始/结束状态、静态等价内容和停止/跳过方式（适用时）。高频操作不使用拖慢任务的演出；交互状态永远有静态反馈，动效不成为唯一信息通道。

### 动效克制与编排原则 (Motion Restraint & Orchestration)

动效服务于信息传达与空间理解，必须克制：
- 严禁滥用非用户触发的机械动效：禁止在每个区块进入视口时都机械地播放 fade-and-slide-up，禁止给每张静态卡片都加上 hover 浮起微动效——这类分散琐碎的动画是典型的 AI 模版特征。
- 集中编排胜于分散动效：一个精心编排的页面初始加载序列（Page-load sequence）或一个贯穿核心叙事的展开过程，远比全屏分散的动效更能建立高级感。
- 交互动效聚焦于响应操作：动效应优先回应用户的直接操作（如菜单展开、面板收起、表单提交状态流转），明确告诉用户状态发生了什么改变。
- 严格遵循 prefers-reduced-motion：在用户开启减弱动效时，提供即时状态切换与完全等价的静态信息。

先建立整组约束：品牌、主体身份、产品几何结构、比例、材质、配色、光线方向、环境、镜头语言和文字安全区。每张记录序号、对应页面章节、要表达的信息、主体与构图、相机位置、进入与离开状态、与前后帧的关系、画幅、目标设备。

复用 Visual DNA 和工具实际支持的参考输入，逐张检查主体身份、产品结构、材质、光线、尺度、环境与镜头推进，而不是只在提示词里写"保持一致"。两端优先共用同一套叙事节点，按需要生成构图变体；设备变体不另计为叙事节点，但新增文件与成本要记录。

退出条件：关键帧真实存在且已查看；每帧有明确页面作用；前后逻辑成立；失败帧已修正。

## 可复用案例：业务驱动的交互动效（Pay8）

适用：已有明确品牌与真实业务内容，用户希望 clean/simple 的网站仍有鲜明交互体验。用户对 Pay8 的 interactive animation 与 React Bits 组合给出正面反馈；这是项目偏好证据，不是转化率、性能或获奖证明。不要复制品牌、商业文案或未经核实的金融功能。

- **先定义交互，再选组件。** 每个候选动效写清用户问题、输入、状态变化、业务解释、可中断性和静态等价内容。Pay8 用服务标签帮助比较，用支付方式选择帮助理解收款，用资金流图解释步骤；展示不代表真实执行交易。
- **形成节奏层级。** 根据内容选择主要交互与一个可选的滚动叙事，其余区块保持安静、及时反馈。数量与顺序由内容决定，不把每区入场、全屏 pin 或大量组件当作丰富度。
- **React Bits 是可适配原料。** 先检查源码、许可和实际依赖，再统一品牌、语义、尺寸与状态。Magnet 保留稳定点击目标，仅让内部标签小幅移动；Spotlight 用品牌浅色强调，不带入库的默认暗色皮肤。文字揭示保留可读的语义文本。不要为单个效果无故增加第二套动画引擎。
- **滚动叙事要解释关系。** Pay8 的 Disburse 场景依次连接指令、接收方与记录，只让图示随滚动推进，正文和条件持续可读。仅当视口与内容真实容纳得下时短暂固定；考虑页头高度、字体加载、窗口变化、放大与长文案。触屏、小屏、短视口或 reduced-motion 使用等价静态结构；精确阈值是项目参数，不是通用标准。
- **快速操作也要正确。** 标签连续切换以最后一次输入为准，稳定布局但不盲目按最高面板预留巨大空白；检查手机每个状态。原生按钮、标签或 radio 支持键盘和可见焦点，触控不依赖 hover。
- **动画必须局部管理。** 监听器绑定组件，按能力查询启用；销毁仅清理自身动画、监听器及上下文，不全局杀死其他 ScrollTrigger。避免逐帧 React 状态更新，并验证卸载和偏好切换。
- **验收真实行为。** 检查首载、重复与快速输入、前后滚动、导航返回、尺寸变化、键盘、触控替代、reduced-motion 和加载失败。保留实际起中终状态截图；构建通过不能证明视觉、流畅度或用户研究。表单校验不可在点击过程中推走按钮；未接通的操作清楚说明状态。

交接时提供逐区动效表：目的 / 触发 / 起中终状态 / 可中断与反向行为 / 设备条件 / 静态回退 / 清理范围 / 验收证据。借鉴这个方法，不强制 GSAP、React Bits、特定颜色或同一套动画配方。

## MiniMax H3 实参

下表是本机 Higgsfield 工具返回过的契约，提交前仍要用 `models_get` 或 `models_search` 复查一次，参数会变：

| 项目 | 值 |
| --- | --- |
| 模型 id | `minimax_h3`（同族 `minimax_h3_max` 提供 480p/768p，需用户确认后才可用） |

| 分辨率 | 只有 `2K` |

## 提交流程

只有关键帧通过检查、H3 可用、输入素材可访问、费用已获授权时才提交。提交前固定三步：选定工作区、用 `estimate_video_cost` 估价、用 `balance` 核对额度，并把本批数量与用途讲清楚。

跨工具传图用 Higgsfield 的上传接口（`media_upload_and_confirm`）取得真实可访问引用。本地路径、其他提供方的 job ID 或虚构 URL 都不是有效引用；无法传输时标记阻塞，不要假装视频引用了这些图片。

逐镜头核对支持的输入模式、媒体数量、类型和互斥限制。目录列出首帧、尾帧和参考角色，不等于它们必须使用或能够同时组合。只传实际支持且有用途的素材，不能默认把剩余关键帧全塞进 image_references。用最少但足够的片段表达叙事。

提示词写清视觉世界、起止状态、主体变化、相机路径与方向、节奏、连续性、光线与文字安全区。滚动叙事要避免无意硬切、闪烁、抖动、结构漂移、模型自己加的字幕和漂浮 Logo；网页文字和控件由 HTML 实现。多段连续时，用前一段实际输出的边界画面指导下一段，核对相机、速度、位置、比例、曝光与主体形态；没有实际核对过就不要说"无缝"。

取回结果后检查开头、中段、结尾和片段衔接。job ID 只代表任务记录，未查看结果就标"未视觉验收"。压缩、转码或抽帧不能说成生成了新视频。超时或状态未知时先查原任务，不盲目重提。

## 网页交付形态

按当前约定，每条视频产出四件套：2K 母版、本地压缩 web 版、poster 静帧、静态回退素材。分辨率本身不能证明性能好坏；依据实际体积、时长、编码、设备与加载时机选择 web 版参数，并核查压缩后的视觉质量、时长和播放。默认不依赖声音；视频失败或禁用时仍可理解和操作。没有转码能力就将该交付项标为 blocked，不能把改扩展名当转码。

所选 H3 不可用时保留全部设计成果并标记依赖它的生成视频阶段阻塞，不自动更换视频模型，也不擅自把 animate 改成 non-animate。

## 实现与验收

按已确认的播放或滚动叙事接入视频，提供 poster、合理加载策略、媒体失败处理和 reduced-motion 回退；放一个自动播放视频不等于完成了滚动叙事。

Build Gate 在通用检查之外另验：视频加载与首屏影响、滚动同步、开启 reduced-motion 后的体验、播放失败回退、移动端表现。


UI motion、3D 与 generated_video 各自记录选择、理由、触发、回退和检查；通过其中一项不证明其他项通过。UI-only animate 的 Build Gate 检查实际 UI 行为，不要求 H3 可用。生成视频已选择时，仍保留 4–10 独立关键帧、预算与实际结果检查，以及 master/web/poster/static 四种交付，不自动取消原视频范围。
